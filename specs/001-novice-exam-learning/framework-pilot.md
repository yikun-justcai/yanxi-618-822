# 全科框架与闭卷重建试点

用户批准：2026-10-19。本文件补充现有规格；不复原早期已废弃的题卡形态。

## 学习路径

全科问题框架 → 章前定位（先修、按课时组织的分支及其关系）→ 原课时 → 闭卷写出结构、解释关系、应用案例 → 展开参考并逐项自评 → 在复习页继续。

两科全局框架均覆盖所有正课模块；导学保留原入口。章前定位与闭卷任务已覆盖两科全部正课章节（618 13 章、822 12 章），不再只限 m3 / p4。

## 数据与行为

- Framework：科目主问题、若干问题分组及模块ID，横贯全科的学习视角。
- Chapter guide：主问题、先修课时、按章节课时组织的 1–5 个分支、关系及证据引用、同一虚构案例、三项闭卷任务与参考。
- 每个分支覆盖该章现有课时；关系解释能链接到支持它的课时及教材依据。
- 固定三个作答维度：结构、联系、应用。参考在学生明确提交后才渲染；提交前全部作答不能为空。
- 草稿即时保存；查看提示单独记录。对照后草稿只读，修改须退出对照并撤销旧自评；新一轮保留上一轮记录。
- 原 v2 科目状态增加 chapters 字段；不改变课程完成判断，不把自评变成自动掌握评分。
- 复习页显示已有章节练习记录，入口回到该章任务。

## 验收

- 全科框架模块齐全，各章课时覆盖、先修及跨章链接有效；引文仍严格回查。
- 旧课程/写作进度迁移无丢失；章节草稿刷新恢复、科目隔离、修改清除旧自评、新一轮保留上一轮。
- 空白不能展开参考；初始参考不在任务DOM；未查看参考不能记录对照自评。
- 390/1440/1728下离线可操作，无页面横向溢出，键盘可完成提交和自评。
- selftest、迁移测试、新路径浏览器测试通过；Better Design 无 critical / serious。
- 产品效果尚需用户试用，不用完成数量宣称教学有效。
